DWEC — Tema 13 (TypeScript) — Práctica

Enunciado

  • Declara variables para representar la información del un alumno
  • Nombre del alumno.
  • Edad.
  • Si está matriculado o no.
  • Lista de notas.
  • Nombre del centro educativo como constante

Ejercicio 1 — Tipos básicos

Enunciado

  • Crear una función que reciba dos números y devuelva su media
  • La función debe devolver un valor de tipo number.
  • Realiza una llamada incorrecta para comprobar que TypeScript detecta el error (después coméntala).

Valores

Enunciado

  • Crea una función llamada saludarque:
  • Reciba un nombre como parámetro opcional.
  • Si se recibe el nombre, muestre Hola, < nombre>
  • Si no se recibe, muestre Hola, invitado
  • La función no debe devolver ningún valor.

Ejercicio 3 — Parámetros opcionales

Enunciado

  • Define una interfaz llamada Producto con los siguientes campos:
  • id
  • nombre
  • precio
  • Crea una variable de tipo Producto y asígnale un objeto correcto.
  • Después, intenta asignar un objeto incorrecto para comprobar que TypeScript detecta el error(comenta esa linea)

Ejercicio 4 — Interfaces como tipo

Enunciado

  • Crea un array con al menos tres productos.
  • Recorre el array y muestra por consola el nombre y el precio de cada producto.
  • Calcula y muestra el precio total de todos los productos.

Ejercicio 5 – Arrays de interfaces

Enunciado

  • Una propiedad nombre pública.
  • Una propiedad edad privada.
  • Un constructor que inicialice ambas propiedaes.
  • Un método presentarse que muestre un mensaje con el nombre y la edad.
  • Crea un objeto de la clase y:
  • Llama al método presentarse.
  • Intenta acceder a la propiedad privada desde fuera de la clase y observa el resultado.

Ejercicio 6 – Clases y encapsulación

Enunciado

  • Define una interfaz Empleado con:
  • id
  • nombre.
  • sueldoMensual
  • Crea una clase EmpleadoEmpresa que implemente la interfaz y que incluya un método para calcular el sueldo anual.
  • Crea un objeto de la clase y muestra el sueldo anual por consola.

Ejercicio 7 – Clases e interfaces

Enunciado

  • Crea una función que:
  • Reciba un número.
  • Lance un error si el número es negativo.
  • Devuelva el doble del número si es válido.
  • Llama a la función dentro de un bloque try / catch y muestra un mensaje de error adecuado en caso de fallo.

Ejercicio 8 – Manejo de errores

Enunciado

  • Crea una función que reciba un parámetro de tipo unknown y:
  • Compruebe si es un texto.
  • Si lo es, lo convierta en mayúsculas y lo devuelva.
  • Si no lo es, lance un error.
  • Controla el error utilizando try / catch.

Ejercicio 9 – Uso de unknown

Enunciado

  • Desarrolla una pequeña aplicación en TypeScript que permita gestionar alumnos.
  • Define una interfaz Alumno.
  • id.
  • nombre.
  • notas (array de números).
  • Crea una clase AlumnoApp que implemente la interfaz y que incluya:
  • Un método para calcular la nota media.
  • Un método que devuelva un resumen del alumno.
  • En el programa principal:
  • Crea un array de alumnos.
  • Añade al menos tres alumnos.
  • Muestra el resumen de cada alumno.
  • Calcula y muestra la media global de todos los alumnos.
